1. Fork the repo to your GitHub repository.
2. Git clone the (new) repository (from the fork).
3. Create a new branch. I did git checkout -b databases/wdata-V0.3
4. Put in the changes: use the VisIt-convert.py script. Note that some of the files must be updated manually.
5. git add, git commit, git push
6. A pull request appears on the original repo page in GitHub. Click it.
7. Follow the instructions. Read carefully what you're doing and what you're selecting. Finally, submit by creating a PR.
