This folder contains various codes for processing of quasiparticle energies.  
Open file and read header for more info about the code.  

Codes:  
* `read-qpe.c`: This file provides template for reading quasiparticle energies from dpca file.
* `read-qpe-below-treshold.c`: Simple code for printing quasiparticle states with energies below the given threshold.
* `track-qpe-evolution.c`: Simple code for printing time evolution of the selected quasiparticle state.
