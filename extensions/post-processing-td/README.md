* `compute-observables-3d.c`: simple code showing how to compute observables like the energy of the flow and the condensation energy for 3d data.
* `compute-observables.c`: the same as `compute-observables-3d.c` but for general dimensionality of data.
* `compute-observables-3d.py`: simple code showing how to compute observables like the energy of the flow and the condensation energy for 3d data, using python.
* `addvar-vs.c`: simple code that computes superfluid velocity.
