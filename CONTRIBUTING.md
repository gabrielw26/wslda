# Contributing to W-SLDA

## For scientists

Science is always about exploring new problems. We are constructing the toolkit to be as flexible as possible, however, it may happen that the present version is not capable to tackle your problem. If this is the case, we encourage you to contact us. We will point you to a section in the code that needs to be updated.

## For computer scientists and students

We invite computer scientists who would like to get involved in the development of W-SLDA Toolkit or related projects.  
Interested persons should contact W-SLDA Team: wslda@fizyka.pw.edu.pl
